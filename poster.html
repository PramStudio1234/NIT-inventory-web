Media Technology (KMUTT) เอกนวัตกรรมมีเดียทางการแพทย์

ปัญหาของกระบวนการเดิม

  • ตารางข้อมูลไม่เป็นระเบียบ (Unstructured Excel): โครงสร้างไฟล์ Excel ต้นทางไม่คงที่และมีเซลล์ผสาน ทำให้คอลัมน์และข้อมูลสต็อกคลาดเคลื่อน
  • คำนวณย้อนหลังล่าช้า (Audit Inefficiency): ขาดระบบสรุปยอดสต็อก ยกยอด-รับ-ใช้ ไปย้อนหลังอัตโนมัติ ทำให้เอกสารสิ้นเดือนล่าช้า
  • การแจ้งเตือนไม่ฉับไว (Communication Gaps): ผู้ดูแลไม่ได้รับแจ้งเตือนทันที เมื่อวัสดุลดต่ำถึงจุดวิกฤตหรือมีคำขออนุมัติเบิกใหม่

โซลูชันเพื่อการใช้งานในองค์กร

  • Dynamic Header Parser: API วิเคราะห์คีย์เวิร์ดตารางอัตโนมัติ นำเข้าข้อมูลสำเร็จ 100% โดยไม่ต้องปรับตารางเดิมหรือล็อกพิกัด
  • Cloud-Native DB Architecture: บริหารผ่าน Firebase DB แสดงผลสต็อกเรียลไทม์ และจัดลำดับรายการอ้างอิงตรงตามไฟล์ต้นฉบับเดิม
  • Automated SMTP Alerting: อีเมล SMTP แจ้งเตือนแอดมินทันทีเมื่อมีคำขออนุมัติ หรือสต็อกพัสดุลดต่ำกว่าจุด Reorder Point

Key Value & Achievements

ลดงานเอกสาร 95% วิเคราะห์นำเข้าข้อมูลอัจฉริยะ
ความคลาดเคลื่อน 0% ตรวจจับหัวตารางและคำนวณแม่นยำ
คลาวด์ Real-time ซิงก์ยอดสต็อกผ่าน Firebase

The Concept

  • Smart Medical Inventory: ยกระดับการคุมคลังวัสดุจากระบบบันทึกมือและตาราง Excel สู่เว็บแอปตัดยอดวัสดุทางการแพทย์แบบรวมศูนย์
  • Intelligent Parser: อำนวยความสะดวกในการนำเข้าตารางข้อมูลด้วยการตรวจจับหัวตาราง และตัดยอดสต็อกแบบเรียลไทม์ 100%
